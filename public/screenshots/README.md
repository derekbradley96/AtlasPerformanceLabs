# App Screenshots for Marketing Site

## coach-home.png

Capture the coach home screen showing:

- Workload score "7" in blue hero card
- Top Priority: "Review Jake's check-in →"
- Roster health: 1 at-risk client in amber
- Quick shortcuts grid

## Capture method

1. Run app locally at 1280×800
2. Navigate to `/home` as a coach with clients
3. Screenshot using your OS tool
4. Save as 1280×800 PNG to this directory

## Interim demo (optional)

Until `coach-home.png` is replaced with a real capture, the repo may ship a tiny placeholder PNG so the hero image URL resolves.

For a fast interim product demo in the **Hero** on `MarketingHomePage.jsx`, you can pass **`embedUrl`** (e.g. `https://www.loom.com/embed/YOUR_ID`) and omit **`screenshotSrc`**. The screenshot path is the long-term approach; the embed is optional for launch polish.
